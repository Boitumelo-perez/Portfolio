# Portfolio
-- This is my Personal portfolio built using Angular Framework for frontend and Django framework for backend. I later on switched from Django Backend as I couldn't find a free yet faster hosting site for my it as opposed to Render where I was hosting it.
-- Currently using a serverless architecture where the logic is held on through a Cloudflare worker GETTING end user inputs from a contact form and POSTING to Resend which send a formatted email to my Designated Email.

# Deployment

- The website is currently live on https://boitumelo-perez.site.je/ 
- I Deployed it using InfinityFree's Hosting services.
 
# How to Run Locally
### Requirements
- Angular framework requires Node.JS to be installed on your machine.
- run node --v
- run git clone [https://github.com/Boitumelo-perez/Portfolio.git ](https://github.com/Boitumelo-perez/Portfolio.git)      
- Run cd '.\Angular Frontend\' to move into the angular folder
- run npm Install
- run ng serve
- run for building into prod run ng build -configuration production
